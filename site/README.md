# QR-генератор спорядження — POC (статичний сайт)

Папка `site/` — статичний сайт без сервера: 3 замокані предмети (мотузка, система, шолом).

## Локально
```
cd site
python3 -m http.server 8000
```
Відкрити http://localhost:8000

## GitHub Pages
1. Запушити репозиторій на GitHub (гілка `main`).
2. Settings → Pages → Source: **GitHub Actions**.
3. Push запустить `.github/workflows/pages.yml`; сайт з'явиться на `https://<user>.github.io/<repo>/`.

QR автоматично бере адресу, з якої відкрито генератор. Після друку міток адресу змінювати не можна.

(Повноцінна версія з базою й адмінкою — Flask-застосунок у `app/`.)
